# Доставка еды 🍕

В течение курса будем собирать один проект: логику сервиса доставки еды. Без интерфейса, только алгоритмы и классы. У каждого свой **модуль**.

## Модули

| № | Модуль | Файл | Что вы должны указать в названии ветки |
|---|---|---|---|
| 1 | Меню | `Menu.java` | `menu` |
| 2 | Корзина | `Cart.java` | `cart` |
| 3 | Промокоды | `Promo.java` | `promo` |
| 4 | Доставка | `Delivery.java` | `delivery` |
| 5 | Время | `Time.java` | `time` |
| 6 | Курьеры | `Couriers.java` | `couriers` |
| 7 | Маршрут | `Route.java` | `route` |
| 8 | Отзывы | `Reviews.java` | `reviews` |
| 9 | Аналитика | `Analytics.java` | `analytics` |

Код лежит в `src/main/java/delivery/`. Общие данные (`DeliveryData.java`) и проверки (`Check.java`) **не меняем**.

## Правила

- Меняем **только свои файлы**, чужие модули не трогаем. Даже если видите в них ошибку: напишите автору в ревью.
- **Один метод — один коммит**, сообщение по делу: `cart: add cartTotal`, а не `исправил`.
- Из рабочей ветки должен быть открытый Pull Request в `main`. Если старый был закрыт — открываем новый.


## Запуск

У каждого модуля есть свой `main` с проверками. Открой файл модуля (например, `Cart.java`) и нажми зелёный треугольник ▶ рядом с `public static void main`.

Вывод в консоли:

```
OK    cartTotal({})
FAIL  cartTotal({0, 0, 3})  ожидалось 77000, получено 0
```

`OK` — метод работает верно. `FAIL` — нет, и выводится, что ожидалось получить и что получилось на деле.

<details>
<summary>IntelliJ подчёркивает package красным</summary>

Правый клик по корневой папке `delivery` → **Mark Directory as → Sources Root**. После этого `package src.main.java.delivery;` станет правильным.
</details>
